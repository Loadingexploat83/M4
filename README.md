## Cómo probarlo
    para probarlo primero debes iniciar el servidor con el comando: npm run dev
    una vez inicias el servidor podras hacer un pequeño formulario en el cual introduces los datos de tu gatete,
    al hacer esto, el servidor mirara a tu gatete, y le pondra un score sobre como es


## Uso de IA
    Se a usado la IA en multiples ocasiones durante esta mision, primero de todo, se uso para resolver un problema en el cual tenia descargado react multiples veces, aparte de esto se uso para hacer consultas sobre como crear la API, que es y como funciona el TanStack Query, como podria implementar el reto de esta mision sin que se viese feo, como usar las mutaciones y decorar la aplicación con CSS

    Prompts Clave:
        "¿Cómo hago que las radios tengan varias opciones de las que elegir?"
        "¿Por qué deberia cambiar algunos campos a `fieldset`?"
        "Explícame qué es TanStack Query y para qué se usa"
        "Y si quiero que mi formulario esté en otro componente así: [código]"
        "¿Podrías hacer que se viese con un fondo negro y otros colores de texto?"
